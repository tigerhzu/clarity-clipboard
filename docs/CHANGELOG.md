# 更新紀錄

## 1.0.14

- 新增「設定 → Hermes」讀寫開關、可跨電腦使用的串接提示詞與複製按鈕。
- 內建 MCP stdio 入口，可搜尋、讀取文字／圖片、儲存及編輯指定項目、建立資料夾、刪除與複製。
- 串接預設關閉，使用本機驗證連線；停用並儲存後拒絕後續存取。
- Hermes 寫入後同步更新目前清單與資料夾數量。

## 1.0.13

- 側欄／清單與清單／預覽的兩條分隔線支援左右拖曳，並保存欄寬；雙擊或 Enter 還原，方向鍵微調，Escape 取消拖曳。
- 視窗縮小時自動保留側欄 180px、清單 300px、預覽 340px 的最小寬度。
- 修正時間篩選日期被擠壓及原生下拉選單跑版；完整日期獨立一列，自訂選單會依空間向上／下展開並支援鍵盤選擇。

## 1.0.12

- 限制同一時間只啟用一個後台；再次啟動會喚回既有視窗，不重複建立監聽器、通知區圖示或快捷鍵。
- 新增複製日曆：有保留紀錄的日期發光，可切換月份、今天及全部時間。
- 選取日期後可繼續搭配分類、搜尋與分頁；月份統計涵蓋完整歷史，不受前 250 筆限制。
- 避免午夜前後的連續去重抹去前一天紀錄；刪除與保留期限清理後，日曆同步更新。

## 1.0.11

- 左側收藏資料夾支援上下拖曳排序，顯示插入位置並保存至本機資料庫。
- 拖曳靠近導覽邊緣會自動捲動；Escape 可取消，亦可用 Alt+↑／↓ 調整資料夾順序。

## 1.0.10

- 所有工作區支援直接新增文字與圖片，Ctrl+N 使用目前目的地。
- 最近複製、收藏資料夾與常用片段皆可編輯標題、內容與類型。
- 支援 PNG、JPEG、BMP 匯入及替換；替換圖片不影響收藏副本。
- 修正歷史搜尋未納入自訂標題；儲存錯誤保留編輯草稿供重試。

## 1.0.9 — 本機工作區與公開文件整理

本節整理 1.0.9 原始碼所包含的功能與本次公開倉庫更新，不將未留存的中間建置逐一推定為獨立正式版本。

### 工作區

- 深色三欄介面：直接可見的內容篩選、歷史清單、獨立閱讀區。
- 圖片原檔、縮圖、放大預覽與缺失圖片處理。
- 資料夾收藏快照、個人片段建立／編輯／複製、拖曳加入與排序。
- 鍵盤搜尋、選取、釘選與刪除確認；常駐通知區及可調整的全域快捷鍵，預設 `Alt + Z`。
- 三種文字大小、首次使用導覽、一般／儲存／隱私設定。

### 本機核心

- Windows 事件驅動擷取、來源辨識、內容規則分類、SHA-256 與短時間連續去重。
- SQLite WAL、FTS5 與部分字串搜尋，歷史分頁及內容／時間篩選。
- 敏感文字規則、排除應用程式、歷史保留與未釘選項目清理。
- 收藏圖片採獨立快照，歷史清理後仍可使用。
- 設定正規化、舊快捷鍵／文字大小偏好遷移、損毀設定復原。

### 安裝與文件

- Windows x64 NSIS、目前使用者安裝與 C# 快速安裝器 `Clarity-Setup.exe`。
- 正常退出事件協助安裝器更新正在執行的背景程式。
- 繁中 README、品牌 Logo 與視覺封面、Mermaid 架構及資料表說明。
- 補齊開發、測試、Release、資料保存與隱私界線文件。
- 以統一入口串連 Freedom Wiki Assistant、HaloPSA Extension 與 Clarity Clipboard。

### 驗證範圍

以 TypeScript／Vite build、Rust 格式／編譯／單元測試、Playwright 假資料介面測試及正式 Windows 產物建置驗證。各次 Release 的實際測試結果和安裝驗證範圍以該 Release 說明為準。
