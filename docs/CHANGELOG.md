# 更新紀錄

## 1.0.9 — 本機工作區與公開文件整理

本節整理 1.0.9 原始碼所包含的功能與本次公開倉庫更新，不將未留存的中間建置逐一推定為獨立正式版本。

### 工作區

- 深色三欄介面：直接可見的內容篩選、歷史清單、獨立閱讀區。
- 圖片原檔、縮圖、放大預覽與缺失圖片處理。
- 資料夾收藏快照、個人片段建立／編輯／複製、拖曳加入與排序。
- 鍵盤搜尋、選取、釘選與刪除確認；常駐通知區及可調整的全域快捷鍵，預設 `Alt + Z`。
- 三種文字大小、首次使用導覽、一般／儲存／隱私設定。

### 本機核心

- Windows 事件驅動擷取、來源辨識、內容規則分類、SHA-256 與短時間連續去重。
- SQLite WAL、FTS5 與部分字串搜尋，歷史分頁及內容／時間篩選。
- 敏感文字規則、排除應用程式、歷史保留與未釘選項目清理。
- 收藏圖片採獨立快照，歷史清理後仍可使用。
- 設定正規化、舊快捷鍵／文字大小偏好遷移、損毀設定復原。

### 安裝與文件

- Windows x64 NSIS、目前使用者安裝與 C# 快速安裝器 `Clarity-Setup.exe`。
- 正常退出事件協助安裝器更新正在執行的背景程式。
- 繁中 README、品牌 Logo 與視覺封面、Mermaid 架構及資料表說明。
- 補齊開發、測試、Release、資料保存與隱私界線文件。
- 以統一入口串連 Freedom Wiki Assistant、HaloPSA Extension 與 Clarity Clipboard。

### 驗證範圍

以 TypeScript／Vite build、Rust 格式／編譯／單元測試、Playwright 假資料介面測試及正式 Windows 產物建置驗證。各次 Release 的實際測試結果和安裝驗證範圍以該 Release 說明為準。
